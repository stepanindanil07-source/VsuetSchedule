# Форматы расписаний ВГУИТ: что обязан учитывать парсер

Знания, накопленные при разборе реальных файлов (осень 2026–2027) и проверенные тестами Java и TypeScript. Источник истины для новых
парсеров. Структура файлов, которую не удалось проверить, здесь не описана: 7 файлов с официальной страницы не исследованы.

## Общее для «сеток» (ФУИТС, ИТФ, ЭХТ, ТФ, ЭУ, СПО)

- **Ничего не зашито по номерам строк и столбцов.** Шапка находится по подписи «Дни» (первые 100 строк), столбец времени по подписи «Часы»,
  «Часы звонков» или «время». Строка с кодами групп это строка с наибольшим числом заполненных ячеек правее столбца времени среди строк,
  которые занимает подпись (у СПО подпись объединена на несколько строк, над кодами лежит заголовок вроде «10 МЕСЯЦЕВ»).
- **Объединённые ячейки.** Текст хранит только левая верхняя ячейка диапазона. Группа занимает столбцы своего объединённого заголовка;
  день это объединённая ячейка в столбце дней (названия ПОНЕДЕЛЬНИК…ВОСКРЕСЕНЬЕ); слот времени это объединённая ячейка в столбце времени.
- **Слот времени.** Две строки: верхняя числитель, нижняя знаменатель. Время «08.00-09.35» или «8.00-9.35»; у СПО 2–4 курсов только начало
  («1) 8 00»), конец = начало + 95 минут (длина каждого явного интервала в файлах), с предупреждением `SLOT_END_DERIVED`.
- **Геометрия занятия внутри слота и группы:**
  диапазон на обе строки это `EVERY_WEEK`, только верхняя строка `NUMERATOR`, только нижняя `DENOMINATOR`;
  на все столбцы группы это занятие всей группы, на один столбец это подгруппа с этим номером (номер среди видимых столбцов);
  на несколько целых соседних групп это общее занятие (поток), оно повторяется для каждой группы.
  Подгрупп может быть больше двух (группы шириной 3 и более столбцов).
- **Часть столбцов группы без указания подгруппы.** Политика формата: ФУИТС отклоняет занятие с ошибкой (`PARTIAL_GROUP_SPAN`), СПО показывает
  его всей группе с предупреждением.
- **Скрытые в Excel столбцы и строки не читаются.** Файлы СПО хранят в них устаревшие группы и занятия (`1_kurs.xls`: 12 столбцов,
  `2-3-4_kurs.xls`: столбцы D–R и EA–EC, 8 групп). Занятие, растянутое на скрытые столбцы своей группы, считается по видимой части.
  Скрытое не пропадает молча: предупреждения `HIDDEN_GROUPS_IGNORED`, `HIDDEN_CELLS_IGNORED` с количеством.
- **Текст вне слотов** (ячейка времени сдвинута относительно занятий) это пропущенное занятие `TEXT_OUTSIDE_TIME_SLOT`, а не молчание.
- **Значение `0`** в ячейке это пустая заглушка, тихо пропускается.

## Курс группы

1. Объединённая полоса над столбцами группы, называющая один курс («2 КУРС» в `2-3-4_kurs.xls`).
2. Иначе имя листа и заголовок, называющие ровно один курс («1 курс», «учебных занятий 1 курса»).
3. Лист, называющий несколько курсов («1, 2 и 5 курсов»: магистры и 5 курс), не говорит, кто есть кто: решает год набора в коде группы
   («Ум-261», «Хм-254» с двумя цифрами года; «ЭБ-61», «УБ-21» с последней цифрой года), НО только если этот курс назван на листе. 245 из 245
   групп с известным курсом подтверждают правило. Магистры очной формы это только курсы 1 и 2.
4. Иначе курс не определён (предупреждение). Учебный год для вычисления берётся у привязанного периода, а не из текста файла.

## ФУИТС, ИТФ, ЭХТ, ТФ, ЭУ (`vsuet-grid-xlsx`)

- Листы по курсам и лист «5 курс + магистры» (названия листов различаются). Семестр указан в шапке («осеннего семестра 2026-2027»): обязателен.
- **Текст занятия:** строка 1 «`тип.предмет`» (`пр.` практика, `л.` лекция, `лаб.` лабораторная; без признака тип OTHER), строки 2+ это
  «Фамилия И.О.   аудитория» (разделитель 2+ пробела; несколько преподавателей и аудиторий в одной ячейке). Допустимы опечатки в инициалах
  («Е.В,», «Л.А», «Д.В..»), фамилия с подчёркиванием («Чекмарева_Пол»).
- Неизвестный признак типа (например «кр.») сохраняется с предупреждением `UNKNOWN_LESSON_MARKER`. Не терять то, что не умеешь классифицировать.
- «Z» и «общ.2» в ячейках: смысл не подтверждён, остаются в исходном тексте и в аудитории как есть.
- `eiu.xlsx`: в тексте ошибка «осеннего семестра 2025-2026», хотя расписание актуальное. Источник привязан к периоду вручную; несовпадение с файлом
  остаётся предупреждением.

## СПО (`spo-xls`, формат XLS)

- Занятие это одна строка свободного текста: `ХИМИЯ (лаб.) 1 под. Черноусова О.В., а. 25`. Разбор по узнаваемым частям: тип в скобках
  (`лаб.`, `практические занятия`, `теория`, опечатки вроде «лоаб.»), подгруппа «1 под.», преподаватели «Фамилия И.О.», аудитория после «а.» / «ауд.»
  или названия «спорт.зал», «актовый зал», «стадион». Тип чаще всего не указан (около половины занятий OTHER): это свойство источника.
- Коды групп с лишними пробелами («ИСП -255») приводятся к «ИСП-255».
- `2-3-4_kurs.xls` не называет семестр: источник должен быть привязан к периоду. Подгруппа, названная в тексте, побеждает подгруппу по столбцу
  (предупреждение `SUBGROUP_MISMATCH`).

## Заочная форма (`zao-xlsx`)

- Один лист, занятия **по календарным датам**: подпись дня «ПНД \n12/10» (день недели + день/месяц, без года). Год берётся у привязанного
  периода как первый, при котором дата не раньше начала семестра; день недели в подписи обязан совпасть с датой (иначе день отклоняется:
  признак неверной привязки).
- Слот времени: две строки. Группа: три столбца [текст, скрытый, аудитория]. Строка 1: «тип. предмет» и аудитория, строка 2: преподаватель
  (и, возможно, вторая аудитория). Признаки типа: `л.`, `пр.`, `лаб.`, `экз.`, `зач.`. Подгруппа в конце названия «- 2 п/г».
- Ячейка предмета в несколько строк это несколько параллельных занятий группы, они сохраняются одним занятием («A / B») с обоими преподавателями
  и аудиториями. Числителя и знаменателя нет, объединений между группами нет.
- Файл не называет семестр и курс: источник привязан к периоду, курс группам задаёт источник (5 курс). Забытые аудитории вне групп (6 ячеек в
  столбце D) считаются одним предупреждением `CELLS_OUTSIDE_GROUPS_IGNORED`.

## Календарь числителя и знаменателя

В файлах не публикуется. Правило владельца проекта: недели чередуются от якоря. Для осени 2026: неделя с 31.08.2026 числитель, семестр
1.09.2026 – 31.12.2026. Календарь помечается как введённый вручную; чётность ISO-недели не используется. Дата вне известных недель периода
это «неизвестно», приложение предлагает ручной выбор.

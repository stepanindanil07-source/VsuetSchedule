# Извлечение плана этажа из изображения (прототип)

`extract.py` и `to_ts.py` превращают растровую схему этажа в данные приложения (`src/plan/generated/…`, формат `src/plan/types.ts`).
Нужны только Python 3 и numpy; изображение сначала переводится в BMP: `sips -s format bmp plan.webp --out plan.bmp` (macOS).

1. Снимок выпрямляется поворотом (`THETA` в `extract.py`, угол подбирается по резкости горизонталей и вертикалей стен).
2. Контур здания и комнаты выделяются по цвету, комнаты приводятся к прямоугольникам, контур к прямым углам (`manhattan`, `remove_spikes`).
3. `labels.json`: подписи комнат `[["105", x, y], …]` в пикселях исходного снимка; `extra.json`: `extraRooms` (помещения без цвета комнаты), `extraCorridors`
   (узкие проходы), `fixRooms` (ручные границы там, где автоматика ошиблась), `stairs`. Эти два файла хранят данные конкретного снимка и в репозитории не лежат.
4. `python3 extract.py plan.bmp labels.json out.json` затем `python3 to_ts.py out.json ../../src/plan/generated/mainFloor1.ts`.

Каталог `src/plan/generated/` в `.gitignore`: результат производный от данных сторонней карты. Для выпуска планы берутся у университета.

## Уточнение крупными кадрами

Если есть крупные кадры того же этажа (плоский вид), они точнее базового:

1. `ocr.swift` (встроенный в macOS Vision, всё локально): `swiftc -O ocr.swift -o ocr && ./ocr кадр.png > ocr/o_кадр.json`.
2. `tiles.py`: кадр выпрямляется и по общим номерам аудиторий (метод наименьших квадратов) переводится в координаты базового; невязка печатается (норма 1–2 пикселя).
3. `build_plan.py base_out.json reg.json каталог_данных out.json`: комнаты и контур из кадров там, где они есть, из базового в остальных местах; общие стены выравниваются,
   наложения разрезаются, проходимые клетки это пол здания без комнат. `manual.json` в каталоге данных задаёт ручные правки после сверки (прямоугольники в пикселях кадра).

После сборки: `to_ts.py out.json ../../src/plan/generated/mainFloor1.ts`.

## Эталон

Приложение показывает только утверждённый эталон `src/plan/etalon/mainFloor1.ts` (экспорт `ETALON_PLAN`), а не рабочие файлы из `generated/`. Эталон лежит вместе с
исходниками (`etalon/source/`: подписи, кадры, файлы правок) и картинкой, файл защищён от записи. Новые правки: собрать в `generated/`, проверить, затем перенести в `etalon/`.
Оба каталога в `.gitignore`, пока репозиторий публичный.
